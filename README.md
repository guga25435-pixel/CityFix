# CityFix: інструкція запуску

Навчальна система обробки міських заявок (C#, Windows Forms, .NET 8, MySQL через XAMPP).

## 1. Що є в архіві

```
CityFix/
├─ CityFix.sln                 ← відкривати цей файл у Visual Studio
├─ Database/cityfix_db.sql     ← SQL-скрипт для phpMyAdmin
└─ CityFix/
   ├─ CityFix.csproj           ← проєкт (NuGet: MySqlConnector, ClosedXML)
   ├─ Program.cs               ← запуск програми
   ├─ Database/Db.cs           ← підключення до MySQL і всі SQL-запити
   ├─ Models/Request.cs        ← модель заявки (SLA: IsOverdue)
   └─ Forms/                   ← MainForm, RequestForm, DispatcherForm,
                                  MasterForm, AnalyticsForm (+ експорт Excel),
                                  PhotoViewForm (кожна має .cs і .Designer.cs)
```

## 2. Підготовка XAMPP (робиться один раз)

1. Відкрийте **XAMPP Control Panel** і натисніть **Start** біля **Apache** та **MySQL**.
2. **Збільште розмір пакета для фото.** За замовчуванням XAMPP не пропускає фото, більші за 1 МБ.
   - Біля MySQL натисніть **Config**, потім **my.ini**.
   - У розділі `[mysqld]` знайдіть рядок `max_allowed_packet=1M` і замініть його на `max_allowed_packet=16M`.
   - Збережіть файл. У XAMPP натисніть **Stop**, потім **Start** біля MySQL.

## 3. Створення бази даних

1. Біля MySQL натисніть **Admin**. Відкриється phpMyAdmin (http://localhost/phpmyadmin).
2. Перейдіть на вкладку **SQL** угорі.
3. Відкрийте файл `Database/cityfix_db.sql` у Блокноті, скопіюйте весь текст і вставте у вікно SQL.
4. Натисніть **Вперед** (Go).
5. Ліворуч має з'явитися база **cityfix_db** з 8 таблицями.

> Скрипт спочатку видаляє стару базу `cityfix_db`. Повторний запуск повертає тестові дані до початкового стану.

## 4. Запуск у Visual Studio

1. Потрібна **Visual Studio 2022** з робочим навантаженням **«.NET desktop development»** (розробка класичних застосунків .NET).
2. Відкрийте **CityFix.sln**.
3. NuGet-пакети (**MySqlConnector** і **ClosedXML**) завантажаться автоматично під час першої збірки. Для цього потрібен інтернет.
   - Якщо цього не сталося: правою кнопкою на рішенні → **Restore NuGet Packages**.
   - Або встановіть їх вручну: **Tools → NuGet Package Manager → Manage NuGet Packages for Solution**.
4. Натисніть **F5** (Start).
5. Унизу головної форми має з'явитися зелений напис **«Підключено до бази даних cityfix_db»**.

Щоб відкрити форму в Designer: Solution Explorer → `Forms` → двічі клацніть `MainForm.cs` (або Shift+F7).

Якщо у вас інший пароль MySQL, змініть рядок підключення в `Database/Db.cs`.

## 5. Як перевірити всі функції

| Що перевіряємо | Дії |
|---|---|
| Створення заявки | Мешканець → ім'я, район, адреса → у дереві оберіть «Прорив труби» → опис → «Вибрати фото...» → «Створити заявку» |
| SLA | Після вибору категорії видно норматив (4 год) і кінцевий термін |
| Фільтр і прострочені | Диспетчер → фільтр «Прострочені». Прострочені рядки показано червоним |
| Фото з BLOB | Диспетчер → оберіть свою заявку → праворуч з'явиться фото «До» → подвійний клік збільшує фото |
| Статус | Оберіть заявку → «Новий статус: На перевірці» → «Змінити» |
| Бригада | Оберіть «Бригада №2 «Водоканал»» → «Призначити бригаду» |
| Майстер | Головна форма → оберіть бригаду №2 → «Майстер» → заявка → «Почати роботу» |
| Матеріали | Труби 2 м → «Додати до списку». Спробуйте ввести 1000 — програма не дозволить |
| Завершення | «Додати фото «Після»...» → «Завершити заявку» → статус «Виконана», залишок труб зменшився |
| Склад | Диспетчер → «Склад матеріалів» → додати матеріал або поповнити залишок |
| Аналітика і Excel | Аналітика → три вкладки → «Експортувати в Excel» → відкрийте файл |

## 6. Можливі помилки

| Повідомлення | Що робити |
|---|---|
| Unable to connect to any of the specified MySQL hosts | MySQL у XAMPP не запущено. Натисніть Start |
| Unknown database 'cityfix_db' | Виконайте SQL-скрипт (розділ 3) |
| Packet for query is too large / max_allowed_packet | Виконайте розділ 2, крок 2 |
| Не знайдено пакет ClosedXML/MySqlConnector | Restore NuGet Packages (потрібен інтернет) |
| Не вдалося створити Excel-файл | Закрийте старий звіт в Excel і збережіть ще раз |
| Українські літери в базі показуються як «????» | Скрипт має виконуватися повністю, разом із рядком `SET NAMES utf8mb4` |

## 7. Ролі та статуси

```
Нова → На перевірці → Призначена бригада → У роботі → Виконана
           ↘ Відхилена
```
- **Мешканець** створює заявку (статус «Нова»).
- **Диспетчер** перевіряє заявку, призначає бригаду або відхиляє заявку. Статус «Виконана» вручну поставити не може.
- **Майстер** натискає «Почати роботу» («У роботі»). Завершити заявку можна тільки з фото «Після». Після завершення статус стає «Виконана», матеріали списуються.
- **Прострочена** — це не статус, а ознака. Її розраховує C#: термін минув, а заявка не виконана і не відхилена (`Request.IsOverdue`).

## 8. Графік у Excel

ClosedXML не вміє створювати «живі» діаграми Excel. Тому метод `DrawChart` у `AnalyticsForm.cs` малює стовпчикову діаграму як картинку засобами System.Drawing. Потім вона вставляється на аркуш методом ClosedXML `AddPicture`.
